# 最近对话

`AI对话/` 里的 599 篇对话，按生成时间从新到旧排，最新的在最上面，一眼就能找到今天/这几天的。

文件名本身就是「日期 + 标题」，所以按名字排就等于按生成顺序排。不用文件系统的「创建时间」，因为那个会被同步、复制重置，文件名里的日期才是当初生成的时间。

> 只列 `AI对话/`，排除 `00 总索引`。想一次看更多，把下面的 `LIMIT 200` 改大（改 1000 就是全列）。想只看某个分类，把 `FROM "AI对话"` 改成 `FROM "AI对话/03 AI 与工具"` 这样。

```dataview
TABLE file.folder AS "分类"
FROM "AI对话"
WHERE file.name != "00 总索引"
SORT file.name DESC
LIMIT 200
```
