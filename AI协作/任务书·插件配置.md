## 1. 这次要达成什么

分两批。**先做第一批，做完停下来等用户在 Obsidian 里点启用并试用。** 用户说「第一批可以」之后，再做第二批。

## 3. 安装方式

**默认：让用户在 Obsidian 里装。** 你不能操作 Obsidian 窗口。

请用户做：

1. 设置 → 第三方插件 → 关闭安全模式（如果还关着）。
2. 浏览，按**显示名**搜索，对照上表的 **id**（插件详情或文件夹名），安装并启用。
3. 只装当前这一批。装完重新加载，或重启 Obsidian。
4. 回来告诉你「装好了」。

你这边同步做的事：

1. `git pull`。
2. 确认 `.obsidian\plugins\` 里出现对应 id 的文件夹，且每个目录有 `manifest.json` 和 `main.js`。`styles.css` 不是每个插件都有。
3. 打开 `manifest.json` 核对 `id` 与上表一致。**不要打开任何 `data.json` 去找 Key**（YOLO 的 `data.json` 里有 API Key）。新插件自己的 `data.json` 只有在第 4 节要求改设置时才可读写，并且不要把内容贴进回复。
4. 看 `.obsidian\community-plugins.json` 是否包含这些 id，以及原来的 `yolo-xox` 是否还在。这个文件在本机，**不要提交到 Git**。

只有用户明确说「你直接下载，我来启用」时，才用 PowerShell 从对应 GitHub 仓库的 **最新 Release** 下载 `main.js`、`manifest.json`，有 `styles.css` 再下。放到：

`.obsidian\plugins\<插件 id>\`

然后把 id **追加**进 `community-plugins.json` 的数组（保留已有项，必须仍有 `yolo-xox`）。下载后先读 `manifest.json` 的 `id`，不一致就删掉刚下的目录并停。不要 `git add` 这些插件文件。

## 4. 设置（第一批）

插件启用后，设置页的文案以用户屏幕上的为准。下面写的是要达到的效果。找不到同名开关时，停下来问，不要猜一个看起来像的开关。

### 4.1 Easy Typing

作者说明：中英文空格、中文标点配对、Tab 跳出配对等，多数开箱即用。见 <https://github.com/Yaozhuwa/easy-typing-obsidian/blob/master/README_ZH.md>。

要改的只有这几项：

| 效果 | 怎么设 |
|---|---|
| 保留 YOLO 的 Tab 补全 | **关掉** Easy Typing 的「Tab 跳出配对符号」。两边都占 Tab 时，补全和跳出都会乱。YOLO 的 Tab 补全在「灵光写作」里，用户可能已经打开 |
| 少改库里的命令和路径 | **关掉**「英文句首自动大写」（名称以设置页为准） |
| 段落保持单换行 | **不要打开**「严格换行」（回车插两个换行） |
| 排除目录 | 若有排除路径：加上 `deepseek-cli` |

其余保持默认。不要导入一份自定义规则 JSON。

和 YOLO 的关系告诉用户：写作时若 Tab 仍然怪，先关 YOLO 的 Tab 补全试一次，或先关 Easy Typing 的自动格式化（命令「切换自动格式化」，默认 `Ctrl+Tab`）。把用户选的结果写进回复。

### 4.2 Quiet Outline

- 用命令面板打开 Quiet Outline，拖到右侧边栏。
- 保持它的特点：**不要**自动展开全部标题（这是相对核心「大纲」的差别）。
- 搜索功能保持打开。
- 核心插件「大纲」可以留着。用户觉得重复时，由用户自己关掉核心大纲。你不要改 `.obsidian/core-plugins.json`，除非用户点名。

### 4.3 Various Complements

- 打开对内部链接 `[[` 和标签的补全。
- 确认键如果默认是 Tab，改成 **Enter**，避免和 YOLO Tab 补全抢键。
- 有中文分词 / Chinese 相关开关就打开；没有就保持默认，不要装额外分词包，除非设置页写明必须装且用户同意。

### 4.4 Dataview

- **不要**打开 Dataview JS（第一批用不到）。
- 行内查询保持默认即可。
- 新建笔记 `仪表盘/未完成待办.md`，正文用下面这段，不要改查询范围以外的现有笔记：

````markdown
---
tags: [仪表盘, dataview]
updated: 2026-10-15
---

# 未完成待办

这页由 Dataview 生成，只读。勾选仍以各笔记里的 `- [ ]` 为准。

```dataview
TASK
FROM "项目进度与待办" OR "AI协作"
WHERE !completed
SORT file.name ASC
```
````

启用 Dataview 之后，请用户打开这篇，确认能看到 `项目进度与待办.md` 里未勾选的任务。若报错，把报错原文写进回复（不要贴 Key）。

### 4.5 Templater

- 模板文件夹设为 `模板`。
- **不要**打开「新建文件时自动套用 Templater」（容易误伤普通新笔记）。用 QuickAdd 指定模板即可。
- 新建 `模板/日记.md`：

````markdown
---
tags: [日记]
created: <% tp.date.now("YYYY-MM-DD") %>
---

# <% tp.date.now("YYYY-MM-DD dddd") %>

## 今天

- 

## 交给 AI 的事

- 
````

- 新建 `模板/交接条目.md`（格式对齐 `CLAUDE.md` 第 4.2 节；编号由用户之后手改，不要让脚本去改 `交接日志.md`）：

````markdown
## #编号 · <% tp.date.now("YYYY-MM-DD") %> · 用户 → 本地 · 状态：待处理

**任务**：

**背景**：

**完成标准**：

**注意**：

**回复**（收件方填写）：

````

建完在回复里说明：这两篇是模板，真正的交接仍要**追加**到 `AI协作/交接日志.md` 末尾，不要把模板整篇贴进去覆盖旧条目。

### 4.6 QuickAdd

加一个 Template 类型的选项，效果：

| 项 | 值 |
|---|---|
| 名称 | 新建日记 |
| 类型 | Template |
| 模板 | `模板/日记.md` |
| 新建位置 | 文件夹 `日记`（没有就创建这个文件夹，放一个空的可不提交的占位？不要提交空笔记；文件夹会随第一篇日记出现） |
| 文件名 | `{{DATE:YYYY-MM-DD}}` |
| 打开新文件 | 是 |
| 出现在命令面板 | 是 |

QuickAdd 的 `data.json` 结构随版本变化。**先读插件目录里的说明或已有 `data.json` 的字段**再写。写之前把原文件复制成 `data.json.bak`（放在插件目录里，不要提交）。结构对不上就停，改为把上表交给用户手动点，不要硬写一份猜的 JSON。

不要添加会执行任意脚本、会改全库文件的 Macro。

## 6. 规则

1. 不要读取、输出、提交密钥。禁止打开：`.obsidian/plugins/obsidian-yolo/data.json`、`.mcp.json`、`~/.deepseek-cli/config.json`、`.obsidian/plugins/yolo-xox/`。
2. 不要设置 `ANTHROPIC_API_KEY`。
3. 不要改 `deepseek-cli/`，不要改 YOLO 源码，不要 `git init`。
4. 不要改 `.obsidian/workspace.json`、`workspace-mobile.json`。
5. 不要修改、移动、删除用户已有笔记。允许**新建**：`仪表盘/未完成待办.md`、`模板/日记.md`、`模板/交接条目.md`。
6. 提交时只 `git add` 这三篇新笔记（以及你在本任务书「回复」里追加的文字、交接日志里你被要求改的状态行）。**不要**提交 `community-plugins.json`、插件 `main.js`、各插件 `data.json`。推送前问用户。
7. 看到文件名带 `conflict` 的副本，告诉用户，不要删。
