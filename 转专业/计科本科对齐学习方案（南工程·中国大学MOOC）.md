# 计科本科对齐学习方案（南工程 · 中国大学MOOC）

> 2026-10-28：按用户要求，**丢掉旧机构周交学习路径**，改写为本方案。目标不是跟培训班交作业，而是对齐**南京工程学院计算机科学与技术**本科培养里的基础与核心知识域，课程内容**以中国大学MOOC（icourse163.org）公开课为主**。

## 0. 依据（写进方案的边界）

### 0.1 学校公开口径（计科）

南京工程学院计算机科学与技术（本科四年）公开材料中的核心知识域包括：

离散结构、基本算法、程序设计、数据结构、计算机组成、操作系统、计算机网络、数据库系统、软件工程等。

培养要求还强调：数学（尤其离散数学）与相关自然科学、外语阅读专业材料、工程与创新意识。掌上高考等公开转载与上述表述一致；学院内部完整课表以教务处 / 计算机工程学院当年培养方案为准，本方案不伪造未公开的学分表。

### 0.2 转专业（I 类）现实约束

- 依据《南京工程学院全日制本科生转专业实施办法（修订）》（南工教〔2025〕146 号）：I 类面向一年级升二年级、第一学年平均学分绩点同班前 40%；学校统一组织考核，重点是**基础课程学习情况、对拟转入专业的了解、学习潜力**。
- **当年考试科目、题型、接收计划以教务处当年转专业通知附件为准**（历史上理工类曾考大学英语、高等数学（工科）、大学物理；现行办法不再写死科目，因此本方案把「高数 / 英语 / 大物」放在**资格与统考蓄水池**，把「计科核心课」放在**专业了解与转入后补修」**两条线并行）。
- 补修风险：若转入后培养方案差异大（理工类补修约 20 学分及以上），可能降年级。提前按计科大一、大二主干自学，降低补修冲击。

### 0.3 明确丢掉的旧路径

不再作为主线：

- 转专业机构每周一发布、周日拍照交群的「高数 14 节 + 严选题一章 + 启航构词法 + 每天 25 词」模板
- 以 `四级与高数学习大纲` / `第二周大纲` 为中心的周交排课
- 把「跟机构交作业」当成完成标准

旧文件已移入 `_archive-旧机构方案-2026-10-28/`。

## 1. 双轨目标

| 轨道 | 目的 | 完成标准 |
| --- | --- | --- |
| A. 转专业统考蓄水池 | 保住 GPA、准备学校统一考核常见基础课 | 高数、大学英语、大学物理能独立完成同济/工科难度习题与真题卷；英语能读简单英文技术文 |
| B. 计科核心对齐 | 对齐专业核心知识域 + 转入后少补修 | 每门主课：看完对应 MOOC 单元 + 完成平台测验/编程题 + 在库里留下一页「自测笔记」 |

两条轨**同时开**，但同一天只主推一门重课（见每周节奏）。

## 2. 中国大学MOOC 课表（主参考）

说明：平台每学期会换开课期（tid），下表给**校方 + 课名**；开课页请在 [中国大学MOOC](https://www.icourse163.org/) 搜课名，优先选国家精品 / 评价高、当前「开课中」或可回看的期次。系列入口也可看 [大学计算机系列课程专题](https://www.icourse163.org/topics/universitycomputer)。

### 2.1 轨道 A：公共基础（转专业考核友好）

| 优先级 | 课程 | 推荐 MOOC | 对齐用途 |
| --- | --- | --- | --- |
| A1 | 高等数学（工科） | 同济大学《高等数学一～四》（周朝晖等）或国防科技大学《高等数学》系列（朱健民等）；习题可配国防科大《高等数学典型例题与解法》 | 微积分主干；与多数工科培养方案一致 |
| A2 | 线性代数 | 同济大学《线性代数》 | 计科后续图形、机器学习、图形学前置；库内原 `线性代数/` 讲义可作练习辅材，**主线以 MOOC 进度为准** |
| A3 | 大学物理 | 电子科技大学《大学物理学1》《大学物理学2》 | 历史统考常客；力学 / 电磁学先过一遍 |
| A4 | 大学英语 | 不绑单一机构词表；MOOC 任选一门「大学英语」读写课 + 每周精读 1 篇短英文技术文（可从 C 课 / 数据结构英文注释取材） | 统考英语 + 培养方案外语要求 |
| A5 | 概率论与数理统计 | 浙江大学《概率论与数理统计》 | 大二常见公共课，提前铺 |

### 2.2 轨道 B：计科核心（按培养核心知识域排序）

| 阶段 | 课程 | 推荐 MOOC | 自测最低标准 |
| --- | --- | --- | --- |
| B0 导论 | 计算思维 / 计算机导论 | 哈尔滨工业大学《大学计算机—计算思维导论》 | 能用自己的话讲清：程序、算法、系统分层 |
| B1 程序设计 | C 语言 | 浙江大学 翁恺《程序设计入门——C语言》；要加深用哈尔滨工业大学《C语言程序设计精髓》 | 独立写：数组、指针、字符串、文件；平台作业过关 |
| B2 离散结构 | 离散数学 | 华南理工大学《离散数学》或北京大学《离散数学概论》（概论偏概念，SCUT 偏系统） | 命题逻辑、集合关系、图的基本证明与计算能下手 |
| B3 数据结构与算法 | 数据结构 | 浙江大学《数据结构》（陈越、何钦铭） | 线性表 / 栈队列 / 树 / 图 / 排序查找；编程题能交 |
| B4 进阶算法（选修加码） | 算法 | 北京大学《程序设计与算法》等 | 递归、二分、基本 STL 用法 |
| B5 系统三件套 | 计算机组成 | 电子科技大学《计算机组成原理》 | CPU / 存储 / 指令 / 总线概念闭环 |
| B5 | 操作系统 | 南京大学《计算机操作系统》（或《操作系统：设计与实现》系列，以当前开课名为准） | 进程、内存、文件系统能画图说明 |
| B5 | 计算机网络 | 哈尔滨工业大学《计算机网络》 | 五层/四层模型、TCP/IP、应用层常识 |
| B6 数据与工程 | 数据库 | 中国人民大学《数据库系统概论》系列 | 关系模型、SQL、规范化基础 |
| B6 | 软件工程 | 哈尔滨工业大学《软件工程专业导论》等 | 知道需求、设计、测试、版本协作在工程里怎么拆 |

实践：程序设计 / 数据结构 / 组成 / 操作系统 / 数据库 / 网络——培养方案列了专业实验。本方案用 **MOOC 编程作业 + 本机小实验** 代替「没实验室也要动手」；专业课笔记落在 `计算机/`（00～08 与课程地图）；Linux 实验见 `计算机/05 操作系统/Linux/`（原节点教程已归档）。

## 3. 学期级路线图（建议顺序，可按转专业日历压缩）

假设从 2026-10-28 起自学，到次年转专业季（通常暑期前后以当年通知为准）至少跑完 **A1～A3 + B0～B3**：

| 时段（约） | 主攻 | 辅攻 |
| --- | --- | --- |
| 第 1～6 周 | B0 导论 + B1 C 语言 | A1 高数每天保持；A4 英语碎片 |
| 第 7～12 周 | B1 收尾 + B2 离散 | A1 继续；A2 线代隔天 |
| 第 13～20 周 | B3 数据结构 | A3 大物开一轮；A5 概率可预习 |
| 转专业季前 8 周 | 压缩复习 A1～A4 真题/模拟 | B3 刷题巩固；扫 B5 导论视频建立「专业了解」话术 |
| 转入后 | 按补修清单对表 B5～B6 | 缺啥补啥 |

若当年通知科目与上表不同：**以通知为准立刻改 A 轨权重**，B 轨不丢。

## 4. 库内交付物（代替「拍照发群」）

每周日自检（写在日记或本方案下方「周志」）：

1. 本周 MOOC：课程名、学到第几讲、测验分数或截图路径  
2. 一道「能讲给别人听」的知识点（3～5 句话）  
3. 代码：本周仓库或笔记里至少 1 个可运行小例子路径  
4. GPA / 原专业课：本周有没有拖学校正课（国家安全、思政、AI 通识等仍按课表上）

寻寻侧：用户说「喵」分享想法 → 归档到 `想法/`；重大进度写入当天 `日记/`。
