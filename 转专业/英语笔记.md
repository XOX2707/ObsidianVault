## 01 · remove、eliminate、terminate

> 起因：2026-10-20 写 smart-catch-the-cat 时拿不准该用哪个词。eliminate 是第一周单词表 Day 3 第 58 个词。

![[remove、eliminate、terminate.svg]]

### 一句话先记住

| 词 | 音标 | 核心意思 | 关注的是 |
| --- | --- | --- | --- |
| **remove** | /rɪˈmuːv/ | 把东西从原来的地方**拿走** | 位置变了（动作） |
| **eliminate** | /ɪˈlɪmɪneɪt/ | 把东西**彻底清除、排除**，让它不再存在或不再算数 | 东西没了（结果） |
| **terminate** | /ˈtɜːmɪneɪt/ | 让一件**持续的事**正式结束 | 时间上到头了 |

重音要注意：e**li**minate 重音在第二个音节，**ter**minate 重音在第一个音节。

### 从词根看（接上构词法网课）

- **remove** = re-（离开、往回）+ move（移动）→ 移开。
  名词：removal。
- **eliminate** = e-（出，就是 ex- 的缩写）+ limin（门槛）+ -ate（动词后缀）→ **赶出门槛外**。
  名词：elimination。同根词：preliminary（pre- 之前 + limin 门槛 → 进门之前的 → 初步的、预赛）。
- **terminate** = termin（边界、终点）+ -ate → **走到终点**。
  名词：termination。同根词：term（期限、学期）、terminal（终点站、电脑终端）、determine（de- 加强 + termin 定界限 → 决定）、exterminate（ex- 彻底 + terminate → 根除、消灭）。

记住三个画面就不会混：**remove 是挪走，eliminate 是赶出门，terminate 是走到头。**

### 区别一：东西还在不在

remove 只说「拿走了」，**不管东西还在不在**；eliminate 强调「没了、不算了」。

- She **removed** the book from the table.（书拿走了，书还在）
- The new medicine **eliminated** the disease.（病没了）
- We **removed** the weeds, but we didn't **eliminate** them — they grew back.（草拔掉了，但没根除，又长出来了）

这句最能看出区别：remove 是动作做完了，eliminate 是问题解决了。

### 区别二：宾语是什么东西

| 词 | 常见搭配 | 中文 |
| --- | --- | --- |
| remove | remove a stain / your shoes / the lid | 去掉污渍 / 脱鞋 / 揭开盖子 |
| | remove sb's name from the list | 把某人的名字从名单上划掉 |
| | remove obstacles / barriers | 清除障碍 |
| | remove sb from office | 罢免某人 |
| eliminate | eliminate poverty / discrimination | 消除贫困 / 歧视 |
| | eliminate errors / risks / the possibility | 消除错误 / 风险 / 排除可能性 |
| | eliminate sugar from your diet | 饮食里完全不吃糖 |
| | be eliminated (from the competition) | （比赛中）被淘汰 |
| terminate | terminate a contract / an agreement | 终止合同 / 协议 |
| | terminate sb's employment | 解雇某人 |
| | terminate a process / a program | 结束进程 / 程序 |
| | This train terminates at Nanjing South. | 本次列车终点站南京南 |

规律：

- remove 的宾语多是**看得见、拿得动的东西**，或者名单、职位上的人。
- eliminate 的宾语多是**抽象的问题**（贫困、错误、风险、可能性），或者比赛里的**选手、队伍**。
- terminate 的宾语一定是**有时间长度的东西**（合同、雇佣关系、进程、服务）。不能说 ~~terminate a stain~~，污渍没有「开始和结束」。

### 区别三：正式程度

remove（日常、中性）< eliminate（偏书面，四级作文常用）< terminate（很正式，法律、医疗、技术用语）

日常说「结束、停止」用 end、stop、finish 就够了：

- ✗ The meeting **terminated** at five.（太生硬，像公文）
- ✓ The meeting **ended** at five.

### 用在人身上要小心

| 说法 | 意思 |
| --- | --- |
| remove sb from office / from the team | 罢免、把某人调离 |
| be eliminated | 比赛中被淘汰（最常用、最安全） |
| eliminate sb（主动） | 除掉某人，在新闻和电影里常是「杀掉」的委婉说法 |
| terminate sb | 美式口语里是「开除」，电影里（《终结者》The Terminator）是「消灭」，正式场合要说 terminate sb's employment |

辩论赛正好用得上：Our team was **eliminated** in the quarter-finals.（我们队在八进四被淘汰了）。希望用不上这句。

### 中国学生常见的错

「消除」不一定是 eliminate，要看消除的是什么：

| 中文 | 地道说法 |
| --- | --- |
| 消除污渍 | remove a stain |
| 消除误会 | clear up a misunderstanding |
| 消除顾虑 | ease / dispel sb's concerns |
| 消除贫困 | eliminate poverty |
| 消消乐里的「消除」 | match、clear（a line / tiles） |

「终止、结束」也不一定是 terminate：日常的事用 end、stop，只有合同、雇佣、进程这类正式的东西才用 terminate。

### 四级作文和翻译里能直接用的句子

- We should take measures to **eliminate** the gap between urban and rural areas.（采取措施消除城乡差距）
- The government has **removed** many barriers to trade.（政府扫除了许多贸易壁垒）
- Either party may **terminate** the contract with 30 days' notice.（任何一方提前 30 天通知即可终止合同）

### 回到写代码

程序里三个词的分工很固定：

| 场景 | 用词 | 例子 |
| --- | --- | --- |
| 从列表、棋盘上拿掉一个东西 | remove | `list.remove(x)`；smart-catch-the-cat 里的 `_removeGroup`、`dead stones are removed` |
| 排除候选、去掉多余的东西 | eliminate | eliminate a candidate move（排除一个候选走法）、eliminate dead code（删掉死代码） |
| 进程、循环、搜索结束 | terminate | the search terminates、terminate the process；对局结束时的局面叫 terminal state |
| 围棋提子 | capture | `captured`，围棋专用词，不用上面三个 |

### 小测

选词填空，用 remove、eliminate、terminate 的适当形式：

1. Please ______ your shoes before entering the room.
2. Our team was ______ in the first round of the debate competition.
3. The company decided to ______ the contract because the supplier was always late.
4. Regular exercise cannot completely ______ the risk of heart disease, but it helps.
5. The cleaner managed to ______ the coffee stain from my shirt.
6. The loop ______ when the cat reaches the edge of the board.

> [!tip]- 答案和理由
> 1. **remove**：脱鞋，具体的东西换了地方，鞋还在。
> 2. **eliminated**：比赛里被淘汰，固定用 be eliminated。
> 3. **terminate**：合同有时间长度，正式终止用 terminate。
> 4. **eliminate**：消除风险，抽象的问题，强调「没了」。
> 5. **remove**：去掉污渍，用 remove。污渍没有开始和结束，不能用 terminate。
> 6. **terminates**：循环是一段持续的过程，结束用 terminate（日常也可以说 ends）。
