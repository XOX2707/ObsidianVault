# 每周学习节奏（计科对齐）

配合 [[计科本科对齐学习方案（南工程·中国大学MOOC）]]。从改版日起用；**不再等机构周一任务**。

## 固定前提

- 作息仍可按你习惯：偏晚睡、偏晚起，全天多在电脑旁
- 学校正课优先：以 `仪表盘/时间表`「每周固定」为准（国安、AI 通识、思政等），旷课不换 GPA
- 主线两轨：A 公共基础（高数 / 英语 / 大物等）、B 计科 MOOC（当前主推一门）
- 长期项目（如 btc-neff）：排在 A/B 与正课之后，赶不上就跳过不补

## 每天骨架（无课日）

| 时间 | 做什么 | 量 |
| --- | --- | --- |
| 起床后 40 分钟 | 洗漱、午饭 | |
| 块 1 · 90～120 分钟 | **当日主课**（本周指定的 B 轨 MOOC 或 A1 高数） | 视频 1～2 讲 + 对应题 |
| 休息 20～30 分钟 | 离开屏幕 | |
| 块 2 · 60～90 分钟 | **辅轨**：另一轨轻量推进（英语精读 / 线代一小节 / 导论） | 不新开第三门重课 |
| 块 3 · 45～60 分钟 | **动手**：C / 数据结构编程题，或物理/高数卷子一页 | 必须留下可复查产出 |
| 傍晚后 | 自由（epub、兴趣） | |

有课日：正课前后各塞一块；砍辅轨，不砍主课。

## 本周主推怎么定（每周日晚 5 分钟）

1. 打开计科方案第 3 节路线图，看自己卡在哪一格  
2. 下一周**只标一门主课**（例如「翁恺 C 语言第 x–y 讲」）  
3. 辅轨写死一门（例如「同济高数：极限运算」）  
4. 发给寻寻或写进日记，避免周中换题

## 周日交付（只给自己 / 库，不给机构群）

- [ ] MOOC 进度一行  
- [ ] 三句话讲清一个知识点  
- [ ] 一个代码或一页习题路径  
- [ ] 正课有没有欠账  

## 明确不做

- 不等待、不围绕「机构每周一 PDF」排课  
- 不把每日 25 词启航表当合格线（单词改挂在英语辅轨，用量自定）  
- 同一天不上两门「第一节都没看完」的新 MOOC
