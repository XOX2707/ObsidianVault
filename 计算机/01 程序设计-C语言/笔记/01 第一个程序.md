# 第 1 讲 · 第一个程序

主课是中国大学MOOC 上的浙江大学翁恺《程序设计入门——C语言》。搜这个课名即可。本讲对齐课程最开头：写出一个能在屏幕上打出一行字的程序。视频可以和这篇对照着看。

这一讲只做三件事：源程序是什么、编译器做什么、程序从哪里开始跑。变量、输入、判断、循环都放在后面。本讲练习没交卷之前，不开始下一讲。

## 从文本到能运行

1. 你写的是**源程序**，文件名以 `.c` 结尾，内容是文本。
2. **编译器**读这份文本，翻译成 **可执行文件** `.exe`。
3. 运行 `.exe` 时，操作系统从函数 `main` 的第一行开始执行。

本机用的编译器是已经装好的 Microsoft `cl`（Visual Studio 2022 生成工具，19.44，x64）。没有另装 MinGW，也没有装 WSL 里的 Linux。每次编译走 `代码/编译.ps1`，脚本会自己载入 VS 的编译环境。

## 最小程序

例子在 [[01-hello.c]]：

```c
#include <stdio.h>

int main(void)
{
    printf("Hello World!\n");
    return 0;
}
```

逐行：

- `#include <stdio.h>`：把标准输入输出的声明拿进来。`printf` 定义在这里。少了这一行，编译器不认识 `printf`。
- `int main(void)`：C 程序从 `main` 开始。`int` 表示结束时交回一个整数。`void` 表示不另收参数。翁恺视频里常写成 `int main()`，和这里是同一件事。
- `{` 和 `}`：包住 `main` 里面要做的事。
- `printf("Hello World!\n");`：把引号里的字印到屏幕。`\n` 是换行，不是斜杠再加一个字母 n 的两个字符。一句的结尾是分号。
- `return 0;`：把 0 交给操作系统，表示这次正常结束。
