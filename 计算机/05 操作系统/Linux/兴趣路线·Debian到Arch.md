# Linux 兴趣路线：Debian → 精通 Arch

> 个人兴趣线，与计科课内 OS/网络**同步学**，不替代 `转专业/` 与 `计算机/01 C 语言` 主推。  
> 实操落点：腾讯云轻量靶机（见 [[想法/腾讯云轻量靶机·购买与部署]]、交接 **#010 / #012**）。

## 目标

1. **近程**：在 **Debian**（系统镜像选官方 Debian，版本跟控制台当前稳定版走，**不锁定 11**）靶机上从「能 SSH」走到「能独立管一台服务器」  
2. **中程**：同一套心智模型在 Debian 大版本之间可迁移（apt、systemd、权限、网络）  
3. **远程**：目标 **精通 Arch Linux**（装机、pacman、systemd、自维护、能读 Wiki 排错）

Arch 不急着上生产靶机；Debian 先把命令、权限、网络、服务、排错肌肉练够，再专门开 Arch 阶段（本机 VM 或另一台机）。

## 阶段地图

### 阶段 D1 · Debian 生存（对接 #010 入门之后）

- 用户与权限、`sudo`、SSH 加固（密钥、非 22 可选）
- apt / dpkg、源、更新策略
- systemd：`systemctl`、`journalctl`
- 防火墙：云安全组 + 主机侧（nftables/ufw 知一层即可）
- 网络基础：`ip`、`ss`、DNS、常驻服务
- 日志与排错习惯

**出门标准**：不看笔记也能装包、开服务、查日志、改 sshd 并自己救回登录。

第一次课笔记：[[D1-00 出门之前]]、[[D1-01 权限与apt]]。

### 阶段 D2 · Debian 熟练

- 分区与挂载、fstab 谨慎改
- 定时任务、备份（rsync 思路）
- 编译工具链、多用户、基础安全（fail2ban 思路，按需）
- 读 man、用 Debian Reference / Wiki 自己查

**出门标准**：能给「干净 Debian」写一份自己的初始化脚本（无面板）。

### 阶段 A0 · 转向 Arch（兴趣高峰）

- 在 **本机虚拟机**（或闲置机）按 Arch Wiki 官方安装指南完整装一遍
- pacman、AUR 工具链、systemd 用户单元
- 滚动发布、镜像、关键排错
- 目标词：精通 = 能无桌面安装器从零装通、坏了敢修、配置可复现
