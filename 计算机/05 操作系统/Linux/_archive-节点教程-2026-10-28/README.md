## 为什么学

目标不是「背 Linux」，而是能**独立掌控一台 Debian 11 VPS**：远程登录、基础加固、网络调优、装面板、开节点并验收。学会后同一套能力可迁移到部署、脚本与自动化。

## 实验范围（Lab Scope）

| 项 | 值 |
| --- | --- |
| 发行版 | **Debian 11（bullseye）** |
| 内核 | 5.10.x（自带 BBR） |
| 包管理 | `apt` / `dpkg` |
| 服务管理 | `systemd`（`systemctl`） |
| 远程入口 | OpenSSH（本机房端口 **非 22**） |
| 实验机 | IP `192.220.37.75`，SSH 端口 `62027`，面板端口 `35123` |

本文只覆盖「从零连上 → 开出第一个可用节点」的最短闭环。本实验机已于 2026-10-28 将面板改为仅监听 `127.0.0.1`（公网不通属预期，经 SSH 隧道访问）。防火墙细配、SSH 密钥等仍放后续课。

## 术语表

| 词 | 含义 |
| --- | --- |
| Linux / Debian | 操作系统；Debian 是稳定的发行版，服务器常用 |
| 命令行 / 终端 | 文本接口；服务器通常无桌面，只留 shell |
| SSH | 加密远程登录（OpenSSH） |
| root | 超级用户；实验初期用，后续应降权 |
| VPS | 虚拟专用服务器 |
| apt | Debian 包管理器；`apt update` 只刷新索引 |
| systemd | 服务与开机自启管理 |
| BBR | TCP 拥塞控制算法；改善长肥管道吞吐，不降低 RTT |
| 3x-ui | 基于 Xray 的 Web 面板（本实验 v3.11） |
| VLESS + REALITY | 轻量协议 + 无需自有证书的伪装握手 |
| Clash Verge Rev | Windows 客户端；本机 mixed-port 以设置为准 |

## 实验室规矩

1. **每条命令先读懂再执行**；不确定就先查 man / `--help`。
2. **密钥与密码永不写入笔记**：用 `<root密码>` / `<面板密码>` / `<uuid>` 占位。
3. **一课一事**：配置过程与概念笔记分开；踩坑单独表记录。
4. **改写配置前先备份**（`cp` 或面板 Backup）。
5. **验收可量化**：课末「验收标准」全部打勾再进下一课。
6. **面板与节点端口分家**：SSH / 面板 / 入站三者不得共用端口。
