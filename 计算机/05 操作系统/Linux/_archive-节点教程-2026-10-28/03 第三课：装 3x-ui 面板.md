# 03 第三课：装 3x-ui 面板

回到 [[计算机/操作系统/Linux/README|学习地图]] · 前置：[[01 今晚第一课：SSH 连上服务器]]、[[02 第二课：开 BBR（网络提速）]]

## 目标

在 Debian 11 上安装 **3x-ui**（本实验实装 **v3.11**），浏览器能打开登录页，服务由 systemd 托管并开机自启。

## 验收标准

- [ ] `systemctl is-active x-ui` 为 `active`（或 `x-ui status` 显示运行中）
- [ ] 能打开面板登录页：装课当天可用公网 `http://192.220.37.75:35123/<面板路径>/`；加固后改为隧道 `http://127.0.0.1:35123/<面板路径>/`（路径形状示例：`/6MIvrTtWZ009J42iMn/`）
- [ ] 面板端口 **≠** SSH `62027`；路径 **≠** `/`
- [ ] 默认弱口令已关闭；密码仅以 `<面板密码>` 形式记录，明文不进笔记
- [ ] 厂商**安全组**已放行面板端口 `35123/tcp`

## 前置条件

- 已 SSH 登录为 root
- 已能 `apt` 正常工作（见 02 课）
- 选定面板端口：本实验 **`35123`**
- 知晓：面板会多占一点内存（1G 机型通常够用），并多一个需防护的 HTTP 入口

---

## 面板是什么

把 Xray 的 JSON 配置变成 **Web 表单**：加节点、看流量、复制链接在浏览器完成。代价是多一个长期运行的服务与攻击面——故端口、路径、密码、后续访问范围都要认真设。

---

## 步骤

### 1. 官方安装脚本（Quick Start）

在 `root@…#` 下执行（仓库：MHSanaei/3x-ui，支持 Debian）：

```bash
bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)
```

| 片段 | 含义 |
| --- | --- |
| `curl -Ls` | `-L` 跟随跳转；`-s` 静默进度 |
| `bash <(…)` | 将脚本内容交给 bash 执行 |

**预期**：交互提问；结束后提示类似：

```text
x-ui v3.11.0 installation finished, it is running now...
…
Fail2ban setup complete.
```

（版本号以脚本当时拉到的为准；本实验笔记对应 **v3.11**。）

### 2. 交互项怎么答

| 问项 | 建议 |
| --- | --- |
| 是否自定义安装 | `y`（自己定端口/账号） |
| 面板端口 | **`35123`**（勿用 `62027` SSH、勿用常被扫的 `2053`） |
| 访问路径 | 随机长路径；**禁止**默认 `/`。可用 `x-ui settings` 查看 `webBasePath`（示例形状 `/6MIvrTtWZ009J42iMn/`） |
| 用户名 / 密码 | 强密码；记为 `<面板用户>` / `<面板密码>`，**不写进 Obsidian** |
| SSL | 本实验选**跳过**（依赖 80 对外开放时易卡安全组）；日后再补证书 |

随机生成的端口、路径、账号、密码：**抄到密码管理器**，笔记里只留占位符。

### 3. 浏览器登录

```text
http://192.220.37.75:35123/<你的webBasePath>/
```

**预期**：出现登录页；用 `<面板用户>` / `<面板密码>` 进入。

### 4. 界面语言（便于对照本课中文菜单）

**Settings（齿轮） → Language → 简体中文**，刷新页面。

#### 英文 ↔ 中文（v3.11 对照）

| 英文 | 中文 | 用途 |
| --- | --- | --- |
| Dashboard | 面板 / 仪表盘 | 概览 |
| Inbounds | 入站 | **加节点** |
| Clients | 客户端 | 配额与用户 |
| Settings | 设置 | 端口、路径、账号、语言 |
| Logs | 日志 | 排错 |
| Config | 配置 | Xray 原始配置 |
| Backup & Restore | 备份与恢复 | 导出/导入 |
| Restart / Stop | 重启 / 停止 | 控制 Xray |
| Xray: Running | Xray：运行中 | 内核存活 |

### 5. 服务侧快速确认

```bash
x-ui status
# 或
systemctl status x-ui --no-pager
x-ui settings
```

**预期**：服务 active；`xray state: Running`；端口 35123；`webBasePath` 非 `/`；`hasDefaultCredential: false`（默认 admin/admin 已关）。安装过程若启用 Fail2ban，同 IP 暴破会临时封禁（常见约 30 分钟，以实机为准）。

常用命令：

| 命令 | 作用 |
| --- | --- |
| `x-ui` | 文字菜单（改端口/路径/账号、重启） |
| `x-ui settings` | 打印当前设置 |
| `x-ui status` | 服务状态 |
| `x-ui log` | 日志 |
| `x-ui banlog` | Fail2ban 相关 |
| `x-ui restart` | 重启面板 |

数据库默认 SQLite：`/etc/x-ui/x-ui.db`（勿把库文件发到公网）。

---

## 验证

1. 安全组：云厂商控制台放行 **TCP 35123** 入站。
2. 本机浏览器打开登录 URL（见上）。
3. SSH 内：`curl -sI http://127.0.0.1:35123/<path>/ | head -5` 应见 HTTP 响应（200/302 等）。

**若浏览器 502、但服务器本地 curl 正常**：多半是本机 Clash **系统代理**把面板流量拐走了。处理见下节与 04 课。

---

## 踩坑 / 回滚

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 浏览器超时 | 安全组未放行 35123 | 厂商后台加规则 |
| 端口冲突 | 端口被占用 | `ss -tlnp \| grep 35123`；`x-ui` 换端口并同步安全组 |
| 忘密码 | — | `x-ui` 菜单重置面板设置 |
| `systemctl` 非 active | 安装失败或崩溃 | `x-ui log` / `journalctl -u x-ui -n 50 --no-pager` |
| 面板经 Clash 一直 502 | 代理无法正确访问该 IP | **临时关系统代理**直连；或加规则让面板 IP **DIRECT**（见下） |
| 误用 `SRC-IP-CIDR` | 规则字段选错 | 对目标服务器用 **`IP-CIDR,192.220.37.75/32,DIRECT`**（不是 SRC-IP-CIDR） |

Clash 规则示例（面板直连）：

```yaml
- IP-CIDR,192.220.37.75/32,DIRECT
```

### 安全卫生（装完立刻做）

1. 端口不用 `2053` 等默认热门值。
2. 路径不用 `/`。
3. 强密码；笔记中永不写明文。
4. Fail2ban 已开则保留；用 `x-ui banlog` 偶尔查看。
5. **面板仅本机（本实验机 2026-10-28 已做）**：监听改为 `127.0.0.1:35123` 后，公网 `35123` 不通是预期，不是挂掉。本机用 SSH 本地转发：  
   `ssh -N -L 35123:127.0.0.1:35123 root@192.220.37.75 -p 62027`  
   再浏览器打开 `http://127.0.0.1:35123/<path>/`。装课当天可先公网通再加固；复训以「隧道可达」为验收。

**回滚 / 卸载**：以官方脚本或 `x-ui` 菜单提供的卸载为准；卸载前先 Backup。勿直接 `rm` 数据库除非已备份。

---

## 一句话记住

3x-ui = Xray 的网页壳；**奇端口 + 长路径 + 强密码 + 安全组**，密码永不进笔记；面板走不通时先排除 Clash 系统代理。
