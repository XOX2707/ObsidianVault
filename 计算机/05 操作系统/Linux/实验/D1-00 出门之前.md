# D1-00 出门之前

本篇是兴趣线阶段 D1 的第一次上机，接在 [[想法/腾讯云轻量靶机·购买与部署]] 的入门之后。到这一步时，应当已经能 SSH、会用 apt，并知道云防火墙和主机上的 ufw。购买和下单步骤不在这里重复。

系统是 Debian，版本跟控制台里当前的稳定版走。

## 现在没有实例

现在没有腾讯云实例。本课里的命令都还没有在服务器上执行。等靶机买好，并且从这台电脑 SSH 登录成功之后，再按 [[D1-01 权限与apt]] 操作。

## 这一次课做完的标准

做完 [[D1-01 权限与apt]] 之后，要能说清三件事：

1. 当前用户是谁。
2. `sudo` 干什么。
3. 用 apt 装上一个包，并看懂一行报错。

## 整段 D1 的出门标准（还没做）

不看笔记也能装包、开服务、查日志、改 sshd 并自己救回登录。

上面这一整段还没做。这一次只写第一次课。改 sshd、自己救回登录，等本课在服务器上做完再开。
