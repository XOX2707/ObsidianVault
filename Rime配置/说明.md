# Rime 配置备份

这里是小狼毫（Weasel）+ 雾凇拼音（rime-ice）的**自定义配置**备份。真正生效的文件在 `%APPDATA%\Rime`，这里只是一份副本，改了这里不会自动生效。

| 文件 | 作用 |
|---|---|
| default.custom.yaml | 只启用雾凇拼音；方案选单只留 F4（去掉和 VS Code 冲突的 Ctrl+反引号）；左 Shift 不切换；Shift+空格 切换中英文 |
| rime_ice.custom.yaml | 所有软件一打开都是英文状态 |
| weasel.custom.yaml | Obsidian 例外，一打开是中文状态 |

## 换电脑或重装后怎么恢复

1. 装小狼毫：`winget install Rime.Weasel`
2. 装雾凇拼音：把 <https://github.com/iDvel/rime-ice> 的文件复制到 `%APPDATA%\Rime`（不需要 README、LICENSE、others、build）。
3. 把这个文件夹里的三个 `.yaml` 复制到 `%APPDATA%\Rime`。
4. 右键任务栏的小狼毫图标 →「重新部署」。

安装记录见 `AI协作/交接日志.md` #005。
