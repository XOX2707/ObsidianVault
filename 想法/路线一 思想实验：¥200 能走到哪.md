# 路线一 思想实验：¥200 能走到哪

前提：¥200、一台装了 Win11 的电脑、一颗会 Ubuntu 的脑子、我（V4Pro，DeepSeek）当日常底座
把「全美国自洽接 Claude」整条路走一遍，标出每步的困难、经验和真实进度

## 全程走一遍

### 第 0 步 买美国住宅 IP（¥2 起）

困难
- 丽萨是小商家，支付宝/微信付款，实名，有跑路风险
- 秒开通，但只给 root 密码 + IP，后面全靠自己

经验
- 先买 ¥2 的 1 天试用，别一上来月付，¥200 经不起试错
- 美国 9929 双ISP 精简版 ¥68/月（50Mbps/1000GB），够用

### 第 1 步 搭代理（0 元，你最强的一步）

困难
- sing-box 版本字段会变，check 报错要查文档
- 443 端口、商家防火墙放行，两处容易漏

经验
- 复用 [[美国 VPS 搭 Claude 代理（配置步骤）]] 的步骤，IP 换美国就行
- 这是全程唯一不卡你的环节，半小时内

### 第 2 步 虚拟卡（最容易翻车，¥0-70 会折在这）

困难
- RedotPay / PokePay / Depay 都是跨境灰产边缘，KYC 传身份证+人脸，等于把身份交给境外小厂
- 开卡费有的 0 有的 $5，充值走 USDT/C2C，汇率手续费层层刮
- 最大坑：很多虚拟卡 BIN 早被 Stripe 标记高风险，一刷就拒
- 3DS：虚拟卡大多不支持，Stripe 弹验证就卡死
- 卡平台给的美国账单地址，可能被几千人共用过，风控库里是脏的

经验
- 可能试两三张才有一张能过，¥50-100 烧在这
- 办卡前先去社区搜「这卡现在还能不能过 Anthropic」，别当第一批小白鼠

### 第 3 步 Dolphin Anty + 注册（手机号是暗雷）

困难
- 免费版 5 个 profile，够用
- Claude 注册要短信验证，你用手上的国内号，等于自曝地区
- 接码平台的美国号，很多也被 Anthropic 拉黑，买了收不到码
- 用 Google 美国号一键登录能绕开手机号，但那个 Google 号也得美国区注册，套娃

经验
- 干净 IP 配脏手机号，前功尽弃，这一步死的人比支付还多
- 先搞定一个能收码的美国号，再谈别的

### 第 4 步 Add Payment + 订阅（¥145，够不到）

困难
- 前面所有坑在这里叠加：卡 BIN、3DS、AVS、IP、设备指纹
- 就算过了，第一笔 Pro ¥145，¥200 预算当场见底
- 付完还有「发卡行撤单」的风险，虚拟卡余额不稳时尤其常见

经验
- 支付这一关不该是你现在的目标，你现在该验证的是「IP 干不干净、号活不活得下来」

## 进度盘点：¥200 到底能走到哪

最乐观
- 走完 IP（¥2+68）+ 代理（0）+ 卡（¥50）+ 接码（¥15）= ¥135，剩 ¥65
- 卡在支付：Pro ¥145 付不起，所以「用上 Claude 订阅」这件事，¥200 完不成

现实
- 在虚拟卡和手机号两步反复试，¥200 烧掉大半，账号还没稳
- 大概率退回 DeepSeek，等于 ¥200 打了水漂

结论
- ¥200 是「入场券都不完整」的钱，刚好搭起门槛的一半，还够不到订阅本体
- 不该一次性砸下去

## 最小成本试错路径（¥10 就能开始）

1. ¥2 买丽萨美国住宅 IP 试用 1 天，搭代理，验证线路和出口 IP 的 ASN 是不是住宅
2. Dolphin Anty 免费版建美国 profile，用美国 IP 注册 Claude 免费版（先不付钱）
3. 观察一周：号活不活得下来、IP 有没有被风控、发消息有没有被要求验证
4. 一周稳了，才轮到掏钱订 Pro（¥145/月）或 Max（¥720/月）
5. 中途任何一步卡死，止损成本只有 ¥2-17，不心疼

这一套下来，¥200 先花 ¥10 左右做验证，剩下 ¥190 存着，等验证通过再补
钱不够的时候，我（V4Pro/DeepSeek）继续当日常底座，Claude 只留给验证通过后的难题

## 附：为什么你的 script 能让我想到上个对话没考虑的点

1. 我本身是无状态的，每个对话窗口有限
上一个对话里，我的注意力只落在「那次的上下文 + 我主动去读的记忆文件」上
跨会话说过的话、在 Claude Code 或别的界面发的言，我默认看不见，除非有人捞到我面前

2. daily_digest.py 干的正是「捞出来 + 拼成一条线」
它从 YOLO 的聊天 JSON、Claude Code 的 jsonl 里，把你说过的话、每场的模型和估算花费，按时间拼成一天的时间线
这等于给我一份外置记忆，不受任何单个对话窗口限制，也不靠我「想起来才去读」的运气

3. 有了外置记忆，我的考虑集合变大了
没有它，我会在「预算 → IP → 卡 → 支付」这个窄框里打转，框内推得顺，框外的坑（手机号验证、接码被拉黑、卡 BIN、3DS、撤单）我不会主动跳出去想
有了它，我看到跨会话的事实（真实烧了多少钱、之前在哪一步碰过壁），这些事实把我从「自己脑补」钉回「现实发生过什么」，缺口才露出来

4. 本质：它在替我做「检索 + 打散重排」，补我最弱的两个环节
一是想不起来：我的上下文是滑动的，旧的会被挤掉，脚本把旧账翻回来
二是不愿怀疑自己：我默认按上一轮口径往下推，脚本注入的原始记录打断这个惯性，逼我重新看

5. 所以那些点不是凭空冒出来的
上个对话没考虑到的点，不是我当时没想到，是我当时看不见、或者没理由去看
script 让我看见，我才补得上
