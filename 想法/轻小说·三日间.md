# 轻小说：《三日间》

> 以 2026-10-23 至 10-25 的三天为底，用三日间（三秋縋）那种冷而克制的文笔改写的轻小说。第一人称。

（一）

那场发作来的时候，我的头先被挤了一下。

不是疼。疼还分得清位置，分得出左和右、前和后。它是整个头颅被什么东西环绕着，往里收。收得没有一处地方能逃，也没有一处地方还属于我。

那天下午，我只想了一件事：了结自己。

这个念头满得快要溢出来。我以为它需要我伸手去够，其实不是。它自己就会从眼眶、从指尖、从任何一道缝里往外漏，兜都兜不住。

我做了个决定。

18:05，我买下第一样东西。18:30，我把一瓶三百六十毫升的真露倒进喉咙，十六度，一气喝完。18:36，又买下第二样。

三样东西，是我同一趟出去，一起备下的。

那粒白色的东西，我先于那瓶酒吃了下去。它本该有某种感觉。我等着。等了很久，没有。

后来我对着酒瓶拍了一张照片，发出去，说：现在打不了嗝，好舒服。

这句话，一半是真的。45克酒精在胃里，确实把昨天那堆事，拽开了一会儿。

（二）

19:36，我在一个群里写下一串字。

45g酒精、一直在打嗝、快撑不住了、1t劳拉2t奥沙、镇静剂人身实验、一直在发麻、快感与恐惧并存、我怎么敢的、已陷入眩晕、双手酥麻、呼吸急促。

我把自己写成了「人身实验」。像我不是那个正难受的人，而是站在旁边、拿着记录本，观察自己的那一个。

室友就在旁边，打着 CS:GO。枪声一下一下，很规律。我听见自己说：在深呼吸。

深呼吸没有用。打嗝变成了两只手彻底麻掉。我问他：晚饭吃了吗。他说吃了。

我不想去医院。

（三）

20:13，手表上的数字是145。

上一笔还停在130。它不是突然跳上去的，是往上爬了一阵，爬到一个我从没在清醒时见过的地方。

手麻刚刚好了一点，胸口就开始闷，然后是大口喘气。再然后，是一种压着的疼。

像有人把手掌按在我的肺上，不松开。

20:27，我说：如果这样能死，我很乐意。

我当时是认真的。

（四）

可我还是拨了电话。

我数过打120要花多少钱。数过爸妈会怎么知道。数过，然后说：那就完了。

我怕被人看见我变成那个样子。所以这个电话，我是押着面子打出去的。

一个一心想了结的人，居然还在替自己撑住最后一点体面。这件事，我到今天也没想明白。

担架是凉的。我光着脚躺上去，车厢的窗边，写着两个字：急救。

我盯着那两个字看了很久。很奇怪，那一刻，我反而什么念头都没有了。

（五）

第二天，我在精神病院的病房里醒来。

床头的柜子上，叠着一条格子的病号裤。

那一天，我没有留下任何一个字。窗外的天是什么颜色，我忘了。有没有人来看我，我也忘了。

我只记得那条裤子，和一种从很深的水底，慢慢浮上来的轻。

（六）

第三天，我自然醒了。

没有闹钟，没有谁来叫。就是醒了过来，像从一层很软的东西里，浮到水面。

我做了一个很长、很高级的梦。

那个梦是从脚底开始的。先是一阵很轻的下坠，然后我的脚掌落在沙上。沙是凉的，却没有一粒沾上我。

天空没有太阳，却亮着。那种亮不像从任何一盏灯里来，倒像有人把「白天」两个字，直接写进了这片世界的设定里。

梦里，世界服从几条命令。/tp 能让我去任何地方，/time set 0 能把天一直钉在白天，/weather clear 能让它永远不下雨。在那里，我像一个管理员，能随时改动这个世界的规则。

我试着开口，喉咙里没有声音。可我心里一动，一行字就浮在眼前。我于是明白，在这里，我不需要手脚，也不需要声音。只要把命令一个字一个字打出来，世界就照着做。

梦里的人都是 NPC。他们只在自己的区域活动，一片沙漠，或者一条街。可他们的举动里，有真人的影子。

有一面垂直的沙墙，高得没有顶。有人站在它面前，洒脱地划着大写字母。

我先认出 TIANA，又认出 HOPE。最后一个，是 LOSANGELES。这个我记得很准。

三个词，竖着排下来，像一列路标。

写它们的人，是我放进这片世界里的一个 NPC。我不认识他。风从墙上刮过去，那些字母不掉一粒沙。像这面墙从一开始，就替我记住了它们。

TIANA，是一个名字。HOPE，是一个我还剩不下多少的东西。LOSANGELES，天使之城。

我想不通它们为什么排在一起。梦里的人不解释，我也没有问。

我也想在墙的最下面，添一个我自己的词。可我站了很久，也想不出该写什么。

然后是一个小女孩。

依母亲的嘱咐，我把她分配在一块地上。那块地是我事先磨光的，月光一样的光滑，像月球表层，宜居，也浪漫。名义上，我只是在旁边随便走走，像在监督。

她按时、标准地把路况交代清楚，一点都不怕，连深夜也不怕。

我忽然想起墙上的第一个词。TIANA。也许那就是她的名字。也许这个名字，早在见到她之前，就已经被写在了墙上。

后来，她迷迷糊糊地意识到，自己还有一个活在世上的母亲。她紧紧依附着我。我摸摸她的头，然后打下一行命令：

/time set 0

我想，这样就能暂时消解掉她对深夜的恐惧。

可我也清楚，我消不掉自己的。HOPE 就挂在墙上，我读得出来，却拿不下来。我又试着打了几条别的命令，没有一条，能把那个词摘下来，递给她。

至于 LOSANGELES，天使之城。我明明可以打一条 /tp，把自己传送到任何地方。可我没有。

在梦里，我守着这一小片沙漠，像所有只会改时间、改天气的管理员一样，哪儿也没有去成。

醒来以后，我细品了很久。在那个维度里，我不过是一个微不足道的管理员。能改时间，能改天气，能瞬移，却改不了任何真正要紧的事。

后来，我试着把这个梦讲出来。讲到一半，我听见自己在给每一处都补上理由，补得太满。像在给一个本来没有意义的东西，硬造一个意义。

我也想过，醒来之后，自己到底还能做些什么。想不出来。

（七）

傍晚，我又被包住了。

是一种苯二氮䓬精心搭起来的梦境。那种舒适，那种安全，在轻轻地拖着我。连出门去见生人，平日里最让我害怕、最需要人际交往本领的事，都变得美好。

仿佛有一个天使，搭在我身边。

我想起沙墙上那第三个词。LOSANGELES。天使之城。原来我早在梦里，就已经把天使认下了。

后来我才说出口：那天使，不过是我自己想象出来的。

每一天，我只是单纯地犯困，然后被奥沙不经意地拉进去。满足了，再走出来。

这一晚，是十五片。

就是这样。

（八）

晚上，我被告知，我在父母那里，彻底失去了信用。生活费、零花钱，我不配。

明天，我要去见校长，谈喝醉酒的事。他们说，我的在校身份，危在旦夕。

我说，被夺走，似乎也在所不惜。

我忽然想起那晚，我一边数着打120要多少钱，一边还是拨了出去。那时候撑着我的是面子。

现在，我连那点面子，好像也快要没了。

只剩那通电话还在。它在说，那晚有一个人，明明算清了所有代价，还是按了下去。

那或许，就是墙上那个词。HOPE。
