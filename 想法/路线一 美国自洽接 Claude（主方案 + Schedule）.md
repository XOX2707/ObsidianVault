## 为什么是这条

全美国自洽，不伪造任何信息
姓名用真实拼音，地址用虚拟卡发卡行的美国账单地址，IP 用美国，Dolphin Anty 用美国 profile
卡、地址、IP 三个地区一致，风控信号最小，出问题能用真实身份申诉

## Schedule（按顺序做）

### Phase 0 办卡（先办，不花钱也能先试）

- [ ] 挑一张美国 BIN 虚拟卡：RedotPay / PokePay / Depay，比开卡费和充值手续费
