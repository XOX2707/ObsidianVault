## 买好后收紧云防火墙

轻量应用服务器里，人们口头说的「安全组」在控制台叫 **防火墙**。它挡的是从外面进来的流量。

新建实例后，默认会放行 ICMP，以及端口 22、80、443、3389。练习机只留 SSH。

- [ ] 打开这台实例的详情，进入 **防火墙**。
- [ ] 去掉或拒绝 **80**、**443**、**3389**。
- [ ] 保留 **22**（Linux 登录）。ICMP 可以留着，方便以后 `ping`。
- [ ] 保存后看一眼规则列表：入站放行里能用来登录的只剩 22。

## 从这台电脑连上去

**PowerShell**（把 `公网IP` 换成回填表里的地址，保留 `root@`）：

```powershell
ssh root@公网IP
```

- [ ] 第一次连接会问 `Are you sure you want to continue connecting`。核对是你刚买的那台之后，输入 `yes` 再回车。
- [ ] 接着输入购买时设的密码。输入时屏幕不显示字符，这是正常的，输完回车。
- [ ] 出现类似 `root@...:~#` 的提示符，表示已经在服务器里。后面的「服务器」命令都在这个窗口执行。

如果 PowerShell 说不认识 `ssh`：到 **设置 → 系统 → 可选功能**，安装 **OpenSSH 客户端**，装完关掉这个终端再开一个，然后重试上面的命令。

本机 SSH 失败、云防火墙又确认 22 是放行的时候，再用控制台网页里的登录当退路。那个入口默认是用户 `lighthouse`。进得去之后，仍然把下面的练习做完，并回到本机把 `ssh root@公网IP` 走通。

## 建一个日常用的用户（可选）

可以先跳过，直接去做后面的「看一眼用户和权限」。要建的话，把下面的 `study` 换成你想用的用户名。

**服务器：**

```bash
adduser study
usermod -aG sudo study
```

- [ ] `adduser` 会问密码，还会问姓名、电话等。姓名那些全部直接回车跳过。密码同样只进密码管理器。
- [ ] `usermod` 跑完没有报错。

**PowerShell**（新开一个窗口）：

```powershell
ssh study@公网IP
```

**服务器**（用 study 登录之后）：

```bash
sudo -i
```

- [ ] 输入 study 的密码后，提示符变成 root。到这一步，新用户才算能用。
- [ ] 在新用户能 `sudo` 之前，不要改 SSH 配置去禁止 root 登录。

## 看一眼用户和权限

用 root 或刚才的 study 都可以。study 看系统文件时，命令前加 `sudo`。

**服务器：**

```bash
id
ls -l /etc/passwd
```

- [ ] `id` 能看到当前用户名，以及所属的组。root 的 uid 是 0。study 的组里应能看到 `sudo`。
- [ ] `ls -l` 最左边一列是权限，例如 `-rw-r--r--`：文件类型、所有者、所属组、其他人各能读还是能写。
- [ ] 这次只看，不对系统目录执行 `chmod 777`。

## 用 systemd 看 SSH 服务

Debian 上 SSH 的服务名是 `ssh`。

**服务器：**

```bash
systemctl status ssh
systemctl is-active ssh
```

- [ ] `status` 里看到 `active (running)`。这个画面可以用 `q` 退出。
- [ ] `is-active` 打印出 `active`。
- [ ] 这次不要执行 `systemctl stop ssh`。停掉之后，这扇 SSH 的门会关上。

## 两层防火墙

门外是腾讯云控制台里的 **防火墙**（上一节已经收成只留 22）。门内是系统里的 **ufw**。两层都要放行，连接才进得来。云防火墙没放行的端口，在机器里放行也没用。

下面会打开机内防火墙。顺序不能反：先放行 SSH，再启用。

**服务器：**

```bash
apt install -y ufw
ufw allow OpenSSH
ufw enable
ufw status
```

- [ ] `ufw allow OpenSSH` 先执行成功（规则里会出现 22/tcp ALLOW）。
- [ ] `ufw enable` 提问时输入 `y`。
- [ ] `ufw status` 显示 `Status: active`，并且 22/tcp 是 ALLOW。
- [ ] 另开一个 PowerShell，再 `ssh root@公网IP`（或 study）一次，确认没有把自己锁在外面。

如果启用 ufw 之前忘了放行 22，本机 SSH 会连不上。用控制台网页登录进去，执行 `ufw allow OpenSSH`，已经启用过就再看一次 `ufw status`。仍进不去时，在网页登录里执行 `ufw disable`，回到聊天里说卡在这一步。不要为了救门去把云防火墙改成全部端口放行。

## 可选：BBR 是什么

拥塞控制决定网络变堵时，这台机器怎么放慢发送。BBR 是其中一种算法。这里只学「怎么看、怎么写进配置」。不拿它做转发，也不安装代理。

**服务器：**

```bash
sysctl net.ipv4.tcp_congestion_control
sysctl net.core.default_qdisc
```

- [ ] 看两行输出。若拥塞控制已经是 `bbr`，下面的写入可以不做，勾上这一节即可。

还不是 `bbr`、又想跟着写一次配置时，再执行：

**服务器：**

```bash
tee /etc/sysctl.d/99-bbr.conf >/dev/null <<'EOF'
net.core.default_qdisc=fq
net.ipv4.tcp_congestion_control=bbr
EOF
sysctl --system
sysctl net.ipv4.tcp_congestion_control
```

- [ ] 最后一行显示 `net.ipv4.tcp_congestion_control = bbr`。到此停止，不要再加别的网络配置。

## 买通之后：换成 SSH 密钥（可选）

密码登录已经能用之后再做。做完之前不要删掉密码登录。

**PowerShell：**

```powershell
ssh-keygen -t ed25519 -f "$env:USERPROFILE\.ssh\lighthouse-lab" -C "lighthouse-lab"
Get-Content "$env:USERPROFILE\.ssh\lighthouse-lab.pub"
```

- [ ] 第一行会问 passphrase，可以再设一层，也可以直接回车。私钥在 `C:\Users\XW\.ssh\lighthouse-lab`，公钥是旁边的 `.pub`。
- [ ] `Get-Content` 打出的那一整行是公钥。把它复制下来。

**服务器**（用现有密码登录进去之后）：

```bash
mkdir -p ~/.ssh
chmod 700 ~/.ssh
```

- [ ] 用 `vim ~/.ssh/authorized_keys` 把公钥粘成单独一行，保存退出。
- [ ] 执行 `chmod 600 ~/.ssh/authorized_keys`。

**PowerShell：**

```powershell
ssh -i "$env:USERPROFILE\.ssh\lighthouse-lab" root@公网IP
```

- [ ] 这条能登录之后，密钥才算配好。私钥不要复制进笔记库，不要 `git add`。
