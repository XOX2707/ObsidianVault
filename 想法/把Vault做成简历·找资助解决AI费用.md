# 把 Vault 做成简历，找资助解决 AI 费用

> 2026-10-18 22:14 说的想法

## 想法的原样

单招进南工程的新大一，想把 vault 补成一份像样的简历，尽快找到人资助，解决 Claude API、Claude 订阅、DeepSeek API 的费用，自己不断产出对别人有用的算法（详情看全部 Repo），苦于找不到平台求助，不想只靠生活费硬扛

## 寻寻的诚实判断

- 思路方向对：想靠作品换资源，是最稳的路，不是天方夜谭
- 顺序反了：先有作品和名气，后才有资助；现在直接找投资人几乎找不到，不是能力问题，是还没到那个阶段
- 陌生人不会资助「还没作品的人」换取「未来的算法」，因为无法验证、无法约束、没有对价

## 资助在现实里真实出现的三条路

1. 开源项目做火 → GitHub Sponsors、爱发电、Patreon 赞助
2. 比赛获奖 → 企业橄榄枝、比赛奖金
3. 实习兼职 → 靠劳动换钱

共同点：作品或名气先到位，钱后到

## 眼前的钱可以压到很低

- DeepSeek API 极便宜，学生量级一个月几块钱
- 本地跑开源模型（Ollama + Qwen / DeepSeek-R1 蒸馏版），几乎零成本
- GitHub Student Developer Pack，用学校邮箱免费拿云额度
- Claude 订阅 20 刀暂缓，高难度任务走 API 按量付，一次几毛钱

## 学校才是现在最实在的「资助方」

蓝桥杯、ACM、数学建模、互联网+、挑战杯的奖金，创新创业训练计划经费，奖学金，这些写在简历上比「有人资助我」硬得多

### 两个要正视的点

- btc-neff 自己的结论是「对方向、幅度、执行都没有可交易的增量」，所以「我能产出对你有用的算法」这句话现在拿不出证据，能拿出的是「我会严谨地验证一个想法，包括证明它没用」
- README 写着「指标构想由 @XOX2707 提出；数学推导、实现与调试由 Claude 完成」，写清楚是对的，但别人一定会问「那你做了什么」。要答得上来：提出问题、定方向、判断和验收，并且能自己讲清 $\kappa(N)=\frac{N}{\pi}\tan\frac{\pi}{N}$ 的泰勒展开和 t 值是什么意思（这就是在学的高数和以后的概率统计）

## 真正可能为你付钱的人（按现实程度排）

1. **学校老师 / 实验室**：最接近「有人投资你」。带着 btc-neff 复盘和猫，去找计算机、自动化方向做 AI 或数据的老师问能不能进组；组里有算力和经费，大创项目立项也有经费（具体额度去教务处或学院通知里查）
2. **竞赛奖金**：蓝桥杯、数学建模、计算机设计大赛
3. **接小活**：用 AI 帮人做脚本、小网页、数据抓取，赚的钱直接抵 API 费，这是「用产出换费用」最直接的形式
4. **国内云厂商的学生优惠**：额度和规则常变，用到时去官网看最新的
5. **GitHub Sponsors / 爱发电**：0 star 阶段收入接近 0，可以挂，别指望
6. Anthropic 的学生和校园计划：Anthropic 不对中国大陆提供服务，基本申请不到，不花时间

## 接小活：去哪接、怎么起步（2026-10-18 22:48 补）

> 用户说「我想接小活」。下面的平台规则和抽成经常变，真要注册时以官网为准

### 平台（按对新手友好程度排）

| 平台 | 适合接什么 | 说明 |
| --- | --- | --- |
| 校内：同学群、学院群、认识的老师 | 数据整理、Excel / Python 批处理、小程序、课题组的杂活 | 最容易起步，信任成本最低；老师那边做好了还可能直接进组 |
| 闲鱼 | 脚本、小网页、格式转换、数据处理 | 学生接单最常见的地方，挂一个服务帖，配作品截图 |
| 程序员客栈、电鸭社区 | 正经外包、远程兼职 | 要简历和作品，竞争比闲鱼正规 |
| 猪八戒网、一品威客 | 各种小需求 | 单子多但压价厉害，新人不容易抢到 |
| Upwork、Fiverr（海外） | 英文需求 | 要英文沟通，收款要绑 Payoneer 之类，门槛高，以后再说 |

### 起步顺序

1. 先在校内接一两单，哪怕便宜甚至免费，换一句「做过什么」
2. 做个作品页：smart-catch-the-cat 的在线试玩链接、btc-neff 的面板，接单时直接甩链接
3. 再去闲鱼挂服务，把校内做过的单子当案例

### 不碰的单

- 代写作业、代做课设、代考：学术不端，被抓到影响转专业和学籍
- 爬个人信息、绕过网站反爬或登录的抓取：有法律风险，只接公开数据、对方有权使用的数据
- 要先交押金、保证金才给单子的：基本是骗局
- 收钱规矩：先收一部分定金再动手，交付后再收尾款

## Patreon 什么时候「用得起」

- Patreon 不用花钱买，是**别人给你打钱**的平台：开账号免费，有收入时平台从里面抽一成左右，再加支付手续费
- 所以问题不是「用不用得起」，是「有没有人愿意每月给你打钱」：要先有一批持续关注你作品的人
- 国内收款不方便（要 PayPal / Payoneer），国内创作者更多用**爱发电**，开通方式差不多
- 现实的时间点：某个项目有了稳定的关注者（比如 GitHub 上有人 star、提 issue，或者有人在你的教程、视频下面催更），那时挂上爱发电 / Patreon 才会有人点；在那之前挂上也没坏处，只是别指望
