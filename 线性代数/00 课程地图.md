# 线性代数 · 课程地图

老师：寻寻（本地 Claude Code）　学生：你

## 怎么上课

1. 打开当前这一课的笔记，从头读到尾，看不懂的地方直接在旁边写 `？？` 或者高亮。
2. 做完文末的练习，把答案写在「你的答案」下面。不会的题先看折叠起来的「提示」，还不会就空着。
3. 回到 Claude Code 对寻寻说「交作业」或者「第 N 课有问题」。寻寻批改、讲解，然后再发下一课。

规则：慢慢来，一课没弄懂就不往下走。

## 参考书：Hefferon《Linear Algebra》

放在 `参考资料/` 里，两个 PDF：

- [[Hefferon Linear Algebra 4th ed.pdf]]：正文，第 4 版，英文，522 页
- [[Hefferon Linear Algebra 习题答案.pdf]]：全书习题的详细解答

来源：作者 Jim Hefferon 的官网 <https://hefferon.net/linearalgebra/>，作者免费公开，许可证是 GNU FDL 或 CC BY-SA 3.0，可以自由下载和保存。2026-10-18 下载。

这本书的特点：从解方程组讲起，例子和习题很多，每章末尾有应用小专题（Topic）。比 Lay 的书更讲究证明，第二章开始会抽象一些，读不顺就以讲义为主，书当作补充。没有讲 LU 分解、对称矩阵和 SVD，这几课只用讲义。

**页码对照**：表里写的是书上印的页码，PDF 阅读器里的页数要 **加 10**（例如书上第 35 页是 PDF 第 45 页）。

## 免费的辅助资料

不用花钱也能配合着看：

- **3Blue1Brown《线性代数的本质》**：B 站有官方中文字幕版，每集十来分钟，动画讲几何直觉，和这套课的思路最搭。
- **MIT 18.06 线性代数**：Strang 本人讲的公开课，MIT OpenCourseWare 免费，网上有中文字幕版本。课程讲到第二单元以后可以配着看。
