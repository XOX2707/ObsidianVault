# 记账规则

2026-10-21 15:55 定的：只记**大的账单**，不记每一杯咖啡。

## 记什么

- 单笔超过 ¥30 的
- 所有 API 和订阅，金额多少都记，因为是自动扣、看不见
- 办卡、充值这类一次付清但摊在后面的

## 一条一条怎么建

`账单/` 里一个文件一笔，文件名 `YYYY-MM-DD 项目.md`，开头写这些属性：

| 属性 | 写法 | 例子 |
| --- | --- | --- |
| 日期 | YYYY-MM-DD | 2026-10-20 |
| 项目 | 名字，尽量跟账单上一致 | Claude Console API |
| 类别 | AI API / AI 订阅 / 吃饭 / 设备软件 / 其他 | AI API |
| 金额 | 只要数字，不要写符号 | 20.25 |
| 币种 | CNY 或 USD | USD |
| 付款方 | 公司额度 / 自己 | 公司额度 |

正文随便写，用来说清楚这笔是怎么来的、退没退、还剩多少。
